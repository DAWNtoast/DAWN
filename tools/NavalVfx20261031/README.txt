Naval VFX validation tooling, 2026-10-31.

CompileProduction.ps1 compiles current production sources using read-only Unity references.
Validate.ps1 leases the existing shipyard-assembly-20261017 validation project.
Capture.cs samples current production naval UI and VFX. It is never installed in UnityClient.

Run Prepare only after source/assets are ready. Run Cleanup after all Unity work finishes.
Shared Library belongs to existing validation tools and must remain in place.

Commands (PowerShell from D:/Game; choose new run/evidence names for each retry):
  ./tools/NavalVfx20261031/CompileProduction.ps1 -Run compile1 -IncludeEditMode -IncludePlayMode -IncludeCapture
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Prepare -EvidenceSet validation
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Test -Run edit1 -TestPlatform EditMode
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Test -Run play1 -TestPlatform PlayMode -TestFilter 'NavalVfx_;BattleLifecycle_;CannonVolley_ShowsMuzzleImpactAndWhiteGuard_ConsumesOneCardAndAnimatesRealHealth'
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Capture -Run capture1 -FrameCount 60
  ./tools/NavalVfx20261031/BuildPreview.ps1 -Run capture1
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Cleanup

Wait until each launched Unity process exits before starting the next stage.
Status reads the selected run log. Targeted source changes can be synchronized with:
  ./tools/NavalVfx20261031/Validate.ps1 -Stage Sync -Run fix1 -SyncFiles 'Assets/_Project/Tests/EditMode/NavalCombatFxGraphicTests.cs'

Capture renders 14 actual production naval UI sequences at 1920x1080 and exports every
legal naval card upgrade mapping. This is deterministic visual sampling, not a gameplay
replay. PlayMode tests separately exercise actual card buttons, costs, targets, hull/guard
timing, selected-area damage, and cancellation. BuildPreview encodes 60 fps MP4 files,
decodes all videos for validation, retains 0.15/0.45/0.70 PNG keyframes and frame hashes,
and then removes the verified intermediate JPGs. It never removes game files.

Resource provenance: outputs/naval-vfx-20261031/asset-provenance.json.
The 1254x1254 RGBA atlas was generated by built-in image_gen and installed without
resampling or pixel modification. No external image API was used. Each 4x4 atlas cell
feeds continuous runtime particle geometry, so the animation has no sprite-frame limit.

Preserved shared dependencies:
  tmp/shipyard-assembly-20261017/Library: SmallTextAudit, WindowFit, ShipyardAssembly,
    existing screenshot tools. Sources are backed up/restored under the task lease.
  tmp/boarding-video-tools/imageio_ffmpeg: existing video encoding helper, reused read-only.
  Artifacts/CardNumbering20261017/UiCompile and UnityClient/Library references: read-only
    compiler inputs used by existing tools. Compiler outputs for this task are removed
    after verification; response files, logs and source hashes remain as evidence.
