# 海盗肉鸽卡牌游戏像素风美术资源

本目录包含 4 张像素风资源板，可作为概念美术、原型素材或后续拆图参考。

## 文件清单

- `ship_sprite_sheet.png`
  - 内容：8 种船只，包括轻帆船、炮舰、商船改装舰、登船舰、幽灵船、帝国海军舰、宝藏驳船、深海教团船。
  - 建议用途：海图单位、船只选择界面、船只图鉴。
  - 建议切分：4 x 2。

- `crew_portrait_sheet.png`
  - 内容：12 名船员头像，包括船长、炮手、航海士、木匠、医生、厨师、水手长、财务官等。
  - 建议用途：船员招募、船员详情、事件对话头像。
  - 建议切分：4 x 3。

- `card_icon_sheet.png`
  - 内容：16 个卡牌技能图标，包括炮击、链弹、燃烧弹、机动、登船、修船、战术、诅咒、掠夺、海军追击等。
  - 建议用途：卡牌插画小图、技能图标、状态提示。
  - 建议切分：4 x 4。

- `resource_icon_sheet.png`
  - 内容：24 个资源和道具图标，包括金币、木材、火药、食物、布料、铁矿、声望、藏宝图碎片、黑珍珠、古代罗盘等。
  - 建议用途：背包、结算界面、挂机远航收益、港口升级消耗。
  - 建议切分：6 x 4。

## 风格约束

- 像素风，复古 RPG / 卡牌游戏方向。
- 主色调：海军蓝、旧木色、黄铜金、帆布米白、暗红、青绿色魔法光。
- 尽量避免直接加入文字、数字和 UI 标签，方便后续本地化和复用。
