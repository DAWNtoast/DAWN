# 海战贴图边缘与出牌响应

## 舰船转向黑边

`PortArt/ship_roster_sheet` 的 2×2 船只图集包含不透明黑色分隔线。原先深蓝背景色键会保留这些黑线，完整图块用于玩家船只、镜像或转向时尤其明显。

- `BattleShipCutout` 根据实际图集设置十纹素安全边界，独立屏蔽格子分隔线，不修改原图、UV、共享材质或船只朝向。
- 黑帆、暗木材、绳索和幽灵船绿色细节仍保留；不能用全局去黑替代图集边界裁切。
- 对双线性纹理先逐纹素抠底，再做预乘透明度插值，防止透明轮廓混入深色底。原有 Point 图集维持单采样路径。
- 贴图后赋值或过滤方式改变时只更新材质参数，不在转向期间重建材质。

## 出牌反馈

模型仍仅执行一次 `PlayCard`，未改变费用、伤害、升级、抽牌或胜负规则。

- 抬牌承诺窗口由 0.48 秒改为 0.22 秒；飞牌、独立增益、护盾、回血和抽牌反馈并行。
- 保留炮口→弹道→命中→血条的顺序；舰位变化在伤害动作完成后执行，避免同时写入船只姿态。
- 转向/位移和距离提示同窗播放；回血、护盾及策略文字分行，避免并行反馈互相遮挡。
- 同阶段保留战场、海面、舰船、防御条和未打出的手牌。仅删除已打出的牌、创建新抽牌、更新数值与局部手牌布局。
- 牌的点击动态读取当前索引，并校验当前战斗、手牌成员与对象状态；支持同名重复牌，已消耗对象的旧回调不会误打下一张。
- 新手引导先还原旧包装，再刷新可用状态和当前红框；动画期间仍防止重复结算。
- 阶段切换、新战斗和胜负离场仍完整构建相应界面，不复用不相容的布局。

## 验证入口

`BattleResponsive_` 回归覆盖三级零费机动/抽牌/加盾、重复牌及过期回调、真实船员复合效果、同阶段敌方回合、阶段切换和胜利离场。

`BattleShipCutoutRenderTests` 使用真实 GPU 渲染验证完整图集四艘船、正反 UV、0°/55°/125°/180° 转向及双线性轮廓，同时检查不误伤黑色细节。

验收记录：`Artifacts/BattleResponsiveness20260916/README.md`。`UI_Battle` 与运行时共用实现，刷新预览即可检查；动态效果请在 Play Mode 战斗中检查。未改变或读取玩家真实存档来执行测试。
