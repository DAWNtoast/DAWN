# 出航码头：切换旗舰与配件装配

出航配置中，水面船位下方独立选船栏的木质箭头直接切换本次出航使用的旗舰。船名和提示在选船栏内，人数、航速与加减按钮位于右下船员配置区。

- 只循环已拥有且能容纳当前货物的船只；不会购买未拥有的船，也不会丢弃货物。
- 只有一艘可用船时两侧箭头禁用。点击时再次检查拥有状态、货舱限制及当前页面，避免过期按钮改变状态。
- 点击船身打开同一艘船的独立配件装配页，关闭装配或使用公共返回入口可回到出航码头。
- 从普通皇家船坞进入的配件装配页仍返回船坞浏览页。
- 装配沿用现有独立船只库存：卸下的部件回到库存，替换不收费，不改变其他船的配置。
- 返回出航时显示实际属性和全部五个配件槽（船角、船身、舰炮、仪器、船帆）；空槽不显示伪造的替代图标。
- 切船/打开档案前提交尚未结束编辑的海图种子；保留海图选择和三阶段牌组，随后出航使用所选旗舰及其配件特殊牌。
- 六港口使用开放水面背景，中央没有连接船体的栈桥、系缆柱或绳栏。前景只保留海图桌边缘和下部准备区；每艘船沿用自己的水线锚点，并按港口应用固定光照色调。
- 船底通过自身龙骨轮廓驱动软入水遮挡、弱近水阴影和断续水纹。水面使用背景同屏采样，切船只更新这两层的轮廓；层节点复用且不拦截点击，静止时不逐帧重建。
- 正常切船仅替换船只预览并更新相关读数、出航条件和按钮绑定，保留海图输入、面板与前景实例。教程、弹窗或导航员能力导致表单结构变化时使用完整刷新。
- 提交海图与切船在同一帧发生时，补给购买绑定当前可见按钮；已退役的旧按钮回调不能再修改状态。

预览与运行时共用布局。`UI_VoyageDeparture` 的编辑预览固定持有初始船，因此箭头显示但禁用，可点击船身验证档案往返，不读取或修改真实存档。

回归测试：`VoyageDepartureShipLayoutTests` 检查六港口布局、配装返回入口及预览来源隔离；`VoyageDepartureShipFlowTests` 检查真实点击、拥有/舱容筛选、配件装卸、状态保留及实际出航。

开放船位验证：`DepartureDockSceneLayoutTests` 检查六港口独立操作区、水线及光照；`DepartureDockRetainedViewTests` 检查切船保留实例、旧回调隔离和同帧海图重报价。`tools/DepartureDockOpenBerth20261017/Run-Validation.ps1` 在隔离工程中运行专项测试并可生成六港口×十二船型截图，不保存或恢复退役预览场景。

新背景为内置 image_gen 编辑输出，资源使用 `voyage_<港口>_open_berth_v1.png`，实际尺寸为 1672×941；旧背景资源保留。提示词与美术清单位于 `Artifacts/DepartureDockOpenBerth20261017/`。
