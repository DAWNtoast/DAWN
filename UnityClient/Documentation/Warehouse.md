# 船长珍藏室

## 仓库

- 左侧为橡木、黄铜与绳饰的六格展示柜；右侧为羊皮纸物品账簿，分「贵重品」和「基础物品」。
- 贵重品：点击右侧藏品，阅读来源与故事；点击左侧展位，再点击「陈列到展位」。默认选择第 1 格。选择展位本身不会移动物品。
- 收回仓库不会删除藏品。每件藏品只能占一个展位，移动会清空原展位，展示布局随存档保存。
- 基础物品：显示十种随船资源；保留木材/铁矿/帆布出售、备用金存回账户、前往后勤采购。
- 贵重品不消耗货舱、不能出售、没有额外战斗数值，不参与返航物资损失。

## 新手奖励与展示教学

第二次教学航行（初航 3/4）使用默认卡组真正击败首领后，出现白色品质部件与「破浪者的罗盘」战利品提示。正常返航、绘图、确认结算后，部件入库、海图收录和唯一罗盘入库一并保存；部件不再自动装配，不要求进入工坊编组。

教学继续要求进入仓库 → 选择罗盘 → 陈列 → 返回港口 → 皇家船坞 → 点击当前旗舰 → 配件页 → 选择「漂木锯齿首」 → 实际装配；用红框和箭头指向当前操作，不置暗其他按钮。陈列后仍需亲自完成部件装配才解锁自由探索，不会通过仅打开仓库、船坞或重载提前完成。未完成展示时退出重进从展示教学继续；已经陈列则从船坞教学继续，不重复发放奖励。

旧版已经完成教学的存档保持自由状态，不自动补发未获得的藏品。旧版未完成陈列、但部件已经自动装配的存档会引导卸下并重新装回同一个部件。新游戏会清空收藏、陈列及展示／装配教学标记。

## 检查

打开 `Assets/_Project/Scenes/UIPreviews/UI_Warehouse.unity` 可查看陈列样本；预览数据与真实存档隔离。预览样本不代表玩家已经拥有该物品。

当前收藏室目录包含 40 种老船长远征遗物。前三件（破浪者的罗盘、航海长的铜钟和封蜡航线图）是教学与主线锚点，其余条目已按探索、旧部传说舰队和港口故事编目，运行时预览可完整浏览。收藏库存按页浏览，最多六件可以同时陈列在展柜中；重复的占位美术会沿用已审核的仓库资源，后续可逐项替换为专属图稿。

美术：`Assets/_Project/Resources/WarehouseV2/`。使用内置 image_gen 创建展示柜与透明罗盘，完整提示词见 `WarehouseArtPrompts.md`。
