# 酒馆占位角色清理

2026-09-16：移除“女巫 · 烬潮”。

## 原因

该身份不在 `CrewNarrativeCatalog` 的正式六职业、六港口角色名册中，也没有对应角色立绘。旧代码在六名入座船员之外额外绘制了单独的招募木牌，并通过独立存档标记给战斗添加专属牌，所以会出现“有招募牌、没有人物”的情况。

## 清理范围

- 删除酒馆额外木牌、签约扣费回调、已登船提示与能力汇总入口。
- 删除该占位身份的特殊卡来源、身份专属牌及旧版女巫职业牌。
- 游戏读档时移除旧招募标记；旧收藏、卡牌经验及强化中的失效记录不再恢复为可用内容。
- 编辑器预览和战斗验收改用正式船员，不再额外注入无形象船员。
- 正式六职业、36 名港口角色保留。暮潮港炮手伊岚有独立的身份、肖像、故事及火焰炮击机制，不属于烬潮占位内容，继续保留。

删除角色不会额外扣除或赠送金币，不清空正常角色、部件或卡组。为兼容旧存档的整数卡牌编号，历史删除位置保留无名称、无来源且不可用的内部槽位；这些位置不进入玩家牌库、收藏或战斗。

`LegacyWitchRecruitedKey` 仅用于删除旧存档标记，不再提供招募或开启能力的入口。测试中仍使用旧角色与卡牌 ID 作为迁移输入，以防残留再次出现。历史验收截图和日志保留作为版本记录，不是运行时内容。

现有 `UI_Tavern` 预览与游戏使用同一构建代码；脚本刷新后不再生成该木牌。若编辑器仍显示缓存，可使用 `Shattered Sail > Scenes > Refresh Open UI Previews`，无需重建或覆盖场景。
