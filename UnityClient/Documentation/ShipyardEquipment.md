# 皇家船坞：船只档案与独立配件

## 入口与三页档案

港口 → 皇家船坞 → 点击船只，打开羊皮纸档案。顶部入口为：

- 船只性能：展示所查看船只当前装配后的船体上限、装甲、火力、航速、舱容及专精。未购买船只展示原装性能。
- 背景介绍：单独显示船只故事，不与性能混排。
- 配件装配：打开全屏二级窗口，保留原顶部 header，背景和控件复用市场二级界面的纸张、胡桃木与黄铜样式。纸张使用低饱和灰米色，船只工位、库存和配件图区采用深墨绿底与浅色字，属性使用浅灰阅读区；选中项用深绿底、浅色字和侧标区分。左侧展示船只与环绕的五个装配槽；右侧顶部按船首、船帆、火炮、船壳、航海仪筛选，下方为闲置配件列表、当前装备、待替换配件和装配按钮。列表可翻页，属性增减用绿／红色标识。

点击纸面左上角返回或按 Esc 关闭装配窗口，回到进入前的性能／背景页。从出航码头或特殊卡牌入口进入时，返回原入口。背景覆盖整个画布并阻挡底层点击，包括超宽或较高比例的屏幕；顶部 header 保持可用。

在库存选择部件后点击装配；已占用槽位会将旧件放回库存。点击卸下同样回库。拆装本身不收金币，不改变旗舰，不会因提高船体上限而免费回复当前船体。未购买船只只能查看，不可拆装。

所有船只（包括初始船「灰鸥」）在装配后均保留基础船只外观，不叠加部件贴图；装配、库存、性能和部件专属战术仍正常生效。此规则在船坞、档案、出航预览、航行和海战中一致。

## 库存与存档

- 每个实体部件有独立实例 ID、原有品质和所属船只；同款部件可同时拥有多件。
- 每艘拥有的船各自保存五个槽位。空槽重载后保持为空；新购买的船提供自己的一套原装件。
- 安装在其它船上的部件需先在该船卸下，再到目标船装配，避免一件同时用于多船。
- 旗舰拆装后立即更新航行性能和部件特殊卡来源；收藏及特殊卡经验不因卸下而抹除。
- 存档键为 `ShatteredSail.ComponentInventory.v2`。旧单套装配按原旗舰迁移并保留品质；其他已有船只初始化独立原装件。
- 商店仍沿用购买后装到当前旗舰的方式，替换件回库。允许购买同款的新实体，每条报价依旧只能购买一次。

## 新手引导末步骤

首领首胜部件仅入库存，不再自动装上。返航结算并完成藏品陈列后，依次引导：

1. 皇家船坞。
2. 当前旗舰。
3. 配件装配页。
4. 库存中的首胜白色部件。
5. 实际装配，之后结束新手引导并开放自由探索。

沿用红框和箭头。该步骤可保存恢复；已完成旧版引导的存档不重新锁定。尚未结束的旧档若已经自动装备奖励，则引导卸下并重新装回同一实体，不重复发放奖励。

## 编辑器检查

`UI_ShipyardDetail` 使用同一运行时构建逻辑。控制器的 `Editor Preview Ship Page`：0 为性能、1 为背景、2 为配件。配件预览使用独立演示库存，不读取或写入玩家实际装配。
