# 目标港口吸附与进港

## 操作与规则

- 点击目标港口图标的任意位置，或点击其附近的海图，会将航点定位到实际码头坐标。附近吸附使用与事件一致的 58 个海图局部像素；事件和港口同时在范围内时选择更近者，同距离保留事件优先。
- 事件图标仍可直接点击，自由海域点击仍可设置自由航点。吸附不会直接执行航行，仍需点击“执行航行”；远程选点继续受原有单次航程限制。
- 航路首领未被击败时，港口继续显示“航道封锁”。可以选择港口航点，但不会绕过首领直接抵港结算。教程阶段的输入限制不变。
- 首领封锁解除后，航线经过原有 1.7 地图单位的进港范围时，航线预判和实际航行都会延伸至码头。已经处于范围内、最后一段不足一海里或已经站在码头的情况也可正常抵港，无需先向外航行。
- 最后一段进港航程计入耗时、淡水、食物和航程经验。补给不足时不移动、不结算、不获得经验；已经在码头的零距离停靠不扣补给。
- 进港连接线不能穿越岛屿，提前遇到的事件仍会中断航行。实际未到海域边界时，不再误扣边缘暗礁伤害。
- 只对目标港口自动进港，经过出发港不会自动返航。抵港结算只发生一次。

## 实现与回归

`CoreGameplayDemoController` 负责目标图标点击与附近航点吸附；`CoreVoyageSession` 负责统一预判航线、进港段计费和结算判定。

`CorePortArrivalTests` 覆盖三海域、进港半径、近距离/零距离、岛屿绕行浮点误差、边界伤害、首领封锁、事件顺序、补给不足和重复结算。`DestinationPortNavigationTests` 使用实际 UI 射线和鼠标点击检查图标边缘、附近吸附、与事件竞争和普通海域选择。
