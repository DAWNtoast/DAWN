# 新手引导：真实玩法流程与检查说明

更新日期：2026-10-16。当前课程使用战棋海战、行动点移动和正式接舷规则。文末的历史测试数量不代表本次验证结果。

## 体验入口

打开 `Assets/_Project/Scenes/MainMenu.unity`，运行后选择「新游戏」。该入口会重置本地存档。已完成旧版引导的存档继续自由探索，不会重新进入课程。

开场漫画后，从港口总览进入「出航码头」，使用正常的目的港、海图和扬帆界面。以下流程以 Unity 源工程为准，旧版 Windows 程序是否包含修改取决于其构建版本。

## 两次出航与归港教学

| 阶段 | 玩家实际操作 | 完成条件 |
| --- | --- | --- |
| 第一次出航：航行与事件 | 向东航行，处理断桅，自选打捞或略过补给箱，查看需要航海士的笔记，主动返港 | 实际处理事件并确认归港 |
| 港口：招募船员 | 在酒馆查看航海士并支付契约金招募 | 正常招募成功 |
| 第二次出航：职业能力与伏击 | 请航海士解读潮汐暗标，避开礁影伏击，继续追踪首领 | 真实处理职业事件与伏击，不进入旧的随机讯息步骤 |
| 第二次出航：战斗课程 | 进入残帆掠夺者遭遇，在分段演习中学习海战与接舷，再完成自由实战 | 最终实战真实胜利；演习本身不发奖励 |
| 首胜归港：海图、仓库与装备 | 主动返航，在结算页绘制海图并确认；陈列「破浪者的罗盘」，亲自装配首胜部件 | 奖励入库、藏品实际陈列、同一部件实际装配成功 |

新航程使用 `NavigatorVoyageLeg = 2` 串联职业事件、伏击和首领。`BossVoyageLeg = 3` 保留给重试及旧版存档兼容，不代表新玩家必须进行第三次出航。

胜利后仍需正常绘图与归港确认，才一次性发放部件与藏品。部件先存入库存，不自动装上；仓库陈列后再进入船坞装配，实际装配才结束引导。重新载入从已完成的里程碑继续，不重复招募、发奖或装配。

## 分段战斗课程

| 演习 | 练习内容 | 核心反馈 |
| --- | --- | --- |
| 航行入门 | 查看资源，点击己舰查看可达区域，拖出前方一格的路线，确认航行并选终向；打出基础机动牌，再移动一次 | 行动点用于移动，能量用于出牌；移动结束清空全部行动点；完成移动和朝向选择后才能继续出牌 |
| 自主转向 | 使用演习预置的 3 行动点，拖出至少两格且包含转弯的路径，撤销或清空后重新规划，选择合法终向 | 首步沿船头；后续可直行或转 90°，不能直接掉头；终向受最后一段航向约束 |
| 炮战与牌组循环 | 查看卡面、射程和敌方意图，装药、开炮、防御、修理、恢复能量、抽牌与结束回合 | 装药和开炮分别支付补给；同名牌当回合费用递增；弃牌、抽牌、洗牌与手牌上限按真实规则发生 |
| 同向接舷 | 在真实同向邻格位置，直接使用当前行动点接舷 | 消耗 1 行动点，不耗能量；无须先打牌或移动 |
| 垂直冲撞 | 前进一步到敌舰侧面，移动清空行动点后打出机动牌重新获得行动点，再发动冲撞 | 消耗 1 行动点，不耗能量；承受与造成冲撞伤害后进入接舷；已有行动点时可以直接冲撞 |
| 接舷卡牌 | 通过正式卡牌效果练习攻击、防御、包扎、抽牌、持续救护和伏击预令 | 目标由船体变为船员；消耗药材；回合结束与下一回合开始效果在对应时点触发 |
| 自由实战 | 自行决定出牌顺序、航线与获胜方式 | 不再锁定唯一卡牌或按钮，沿用正常战斗判定；真实获胜才推进外层首胜流程 |

章节结束后，由玩家明确选择开始下一段演习。章节切换时重置练习船位、预排教学牌堆及演习补给；同一章节内不在每回合清空并重造手牌。章节切换、重试及提前退出练习时恢复入课士气，进入最终实战时也从该基线开始，避免重复冲撞练习累积优势；最终实战正常获得或损失的士气按普通规则保留。课程使用基础等级的教学牌堆，不覆盖玩家拥有的牌组、升级和船员。前六段可以重试，最终实战禁止重新整备演习，失败走正常返港结算。

资源、敌情、牌组与卡牌说明是只读检查，悬停和关闭查看窗口始终可用。课程限制作用于当前尚未开放的提交动作，不阻止阅读。移动使用同一套拖动路径规划界面，由玩家决定中途航线与合法终向，不要求固定向东。

## 一致的战斗规则

- 网格每格为 100 × 100 米，默认初始距离 600 米。每个远程海战回合开始获得 1 行动点和 3 能量。
- 炮击射程为 4 格：横向格数与纵向格数相加不超过 4，不按直线米数计算。右 3 格、上 2 格合计 5 格，不能炮击；右 2 格、上 2 格合计 4 格，可以炮击。
- 点击我舰图标时，同时显示移动海域和基础炮击、当前手牌伤害效果的攻击范围；重叠格优先使用蓝绿色移动填色，仅可攻击的格子显示红色。再次点击收起攻击和移动范围，已选航线仍保留。悬停伤害牌时，攻击范围临时切换为该牌射程，重叠格仍优先显示移动颜色；移开后恢复我舰攻击范围。红格不表示资源足够出牌；能量、弹药或职业条件不足时仍可预览。装填、回复和防御牌不产生专属攻击范围。
- 移动牌改为增加行动点。玩家可以交替出牌与移动；确认航行后普通行动点清空，未用于路线的点数仅保留到本次终点确认阶段，可支付接舷或冲撞。选择普通朝向停船后，该余量清空，须重新获得行动点才能再移动。移动动画与终点动作完成前不能出牌。
- 点击己舰显示当前行动点内所有可达海域，以蓝绿色填充和边框标识；从船上直接按住拖动也可开始规划。鼠标拖出连续航线，松开保留金色预览；从末端继续拖，拖回已选格子可撤回。规划本身不扣行动点、不移动船只，点击确认航行后才执行。非法段不会加入路线，玩家可以撤销或清空后调整。
- 路径不能原地掉头。最终朝向可保持最后一段航向或向左右各转 90°。例如面朝东，从原点经东、北两格到达右上格，终向可东、北、西；如需朝南，必须选能以东、南或西到达的更长合法路线，行动点必须覆盖实际格数。
- 冲撞和接舷均支付 1 行动点，不支付能量。仅上下左右相邻一格合法；斜向、隔格和重叠不算相邻。
- 同向可接舷，逆向不可接舷；冲撞要求双方垂直且发起方船头指向对方。当前有行动点且几何条件满足即可直接使用，不依赖此前是否移动或打过卡。
- 到达终点、尚未确认朝向时，若剩余移动预算至少 1 点，可直接按接舷或冲撞按钮；按钮同时确定该动作所需的合法终向。例：持有 2 行动点，与敌舰中间隔一格，航行一格到相邻位置后，可用剩余 1 点接触。所需终向必须属于本次到达的合法三选一，仍不能原地掉头；预算不够或位置、朝向不符时按钮不可用。普通停船不会把余量返还为可自由使用的行动点。
- 敌方炮击先按有效装甲减伤，再由格挡吸收；冲撞按舰艏和船体强度计算并穿透格挡。接舷采用正式近战卡牌、士气暴击与回合触发规则，不使用旧教程的简化卡牌效果。
- 装药与实际射击分别计算火药，射击还消耗炮弹；修理与包扎按实际木板、药材供应执行。有无补给的效果以当前卡面与资源读数为准。
- 同一张牌的不同副本共享当回合同名使用次数，每次成功使用增加后续费用；新回合重置。手牌上限为 8，抽牌堆耗尽后按正常规则洗入弃牌。

## 存档、奖励与恢复

- 战斗课程不保存半场状态；没有可恢复航程时，从出航前港口快照重试，保留已招募船员和自有牌组。暂停只结束已提交的动画，不重复执行行动。
- 七段课程使用临时训练配给：火药、炮弹、木板、药品各 20。课程结束时先恢复入课个人补给，再执行正常航程结算；失败仍按普通损失规则处理，不把分段整备变成永久库存收益。只有最终实战胜利才记录首领已击败并进入胜利奖励流程。
- 已记录胜利、但尚未结算的海图恢复继续返港与绘图，不要求再次打首领。归港确认、陈列和装配都具备独立恢复步骤，重复点击和重新载入不重复发放奖励。
- 失败或未完成就返港时开放正常采购与仓库物资出售，按普通损失和返航规则整备重试。课程内不提供普通撤退；接舷前若实际口粮不足以承担撤离成本，仍可使用正常应急拖救并按失败保护率结算，不直接完成课程或补满个人库存。
- 旧检查点和已完成标记保留兼容。旧完成档不重新锁定；旧版已自动装上的首胜奖励可在陈列后卸下并装回同一部件，不补发副本。
- 完成装配后显示「恭喜完成引导，接下来开始自由航行吧」，完整停留 3 秒、淡出 3 秒；可以继续操作，不因刷新重播，已完成存档加载也不重播。
