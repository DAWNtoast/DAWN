# 新手引导：真实玩法流程与检查说明

当前流程更新日期：2026-09-30。文末保留此前版本的历史验证记录。

## 体验入口

在 Unity 打开 `Assets/_Project/Scenes/MainMenu.unity`，运行后选择“新游戏”。新游戏会重置当前本地存档，已有存档请先备份。已完成旧版引导的存档保持自由探索，不会被重新锁定。

以下流程以当前 Unity 源工程为准；此前交付的 Windows exe 是否包含这些修改，应以其构建记录为准。

## 三次真实出航与首胜后的港口教学

| 教学阶段 | 玩家实际操作 | 通过条件 |
| --- | --- | --- |
| 初航 1/3 · 航行与事件 | 从正常出航界面进入第一张海图的近港教学水域，向东航行，处理航道断桅、自由选择打捞或略过漂流补给箱、查看无法辨认的潮汐笔记，主动返航并确认结算 | 三个教学事件已处理；船员专属选项暂不可用 |
| 初航 2/3 · 招募船员 | 正常进入酒馆，查看航海士档案，支付契约金招募 | 实际招募成功；当前教学候选契约金为 105 金币 |
| 初航 2/3 · 航海士事件 | 再次从出航码头选择第一张海图，向东航行 120 海里，选择航海士的职业选项解读「潮汐暗标」 | 实际解读成功后进入普通抵达结算；确认结算抵达所选目的港，开放第三次出航 |
| 初航 3/3 · 首领战 | 第三次出航，向东航行 120 海里遇到残帆掠夺者并选择交战；使用默认策略、远程、近战卡组和随船航海士的专属卡进行正常海战 | 实际赢得教学首领战；无需进工坊或修改任何牌组，不再经过旧的随机讯息和伏击撤退航段 |
| 初航 3/3 · 首胜展示与装配 | 胜利后主动返航，在结算页绘制海图并确认结算；进入仓库选择并陈列罗盘；进入皇家船坞，点击当前旗舰，在「配件」页选择首胜部件并装配 | 战利品真正入库，玩家亲自完成藏品展示和首胜部件装配 |

第三次航行的首领战胜利后显示白色品质部件“漂木锯齿首”与贵重品“破浪者的罗盘”，确认归港时一次性将部件存入库存并收藏罗盘，不再自动装配。接着要求玩家进入仓库、选择罗盘、实际陈列，再到皇家船坞进入当前旗舰介绍，选择「配件」页和库存部件，亲自点击装配。只有实际装配成功才解除教学锁定，此后可返回港口首次进入藏宝图桌。展示前退出从仓库教学继续；陈列完成后退出从船坞教学继续，不重发奖励。详见 `Warehouse.md`。

## 与普通玩法一致的规则

- 三次教学航行都使用正常出航、航行消耗、事件选项、船员、战斗和结算接口。固定的是教学海域、事件顺序和向东航向。
- 事件所在海域是第一张海图的近港教学子区域。首领是可定位的敌舰；船内潮汐笔记不会变成可定位地标。新流程不再进入旧的随机事件/伏击撤退航段。
- 招募正常扣费。教学不赠送额外升级、不免费恢复补给，不改动普通海图 boss 的数值。自由探索后的卡组构筑功能保持不变。
- 新手 boss 使用独立的较弱敌舰配置，可用未强化的默认基础卡组和新招募的航海士击败。仅教学首领战的抽牌堆使用默认基础卡组，正常加入随船特殊牌，不覆盖旧存档已编组的牌组。
- 结算的“绘制海图”是共享的正常功能。需具备航海士能力且不是失败结算；记录探索格、可见位置、海图种子与哈希，确认归港后保存。首次绘图教学位于首胜结算页，并非藏宝图桌；相应的可编辑预览为 `TutorialVoyage/28_DrawChart.unity`。教学记录标注为近港教学水域。

## 引导锁定与异常恢复

- 当前需要操作的控件使用红色矩形框和指向该框的箭头标注。标注跟随控件的位置与尺寸，不遮住文字、不拦截点击；场景和其它按钮不再因教学而置暗。
- 每一段航行依次引导：点击「东」→在航程滑块选择 120 海里→点击「执行航行」。拖动过程中仍使用普通航行预测；松开滑块、点击滑块或键盘确认后才进入下一步，错误航程不能越过教学。初次出航、事件选项、招募、首领交战、出牌、返航、绘图、藏品展示及船坞装配沿用同一套红框和箭头。
- 装备教学使用普通船坞库存与拆装接口，保留部件实例身份和品质，替换的旧部件回到库存。只有点击实际装配按钮才完成；打开详情、切换页签、选择部件和重载都不会自动完成。库存有多页时自动显示教学部件所在页，但不会替玩家选择或装配。
- 未完成旧版仓库教学、但奖励已被旧版本自动装上的存档，在陈列后引导卸下并重新装上同一个部件，不补发副本。已完成旧引导且没有待办标记的存档保持自由探索。装备待办使用独立持久化标记，不修改旧检查点编号。
- 步骤之外的按钮仍有透明输入保护，阻止误操作及已缓存的按钮回调绕过流程；不会套用教学置暗效果。普通规则导致的不可用状态（例如金币、能量或船员不足）保持原有提示。
- 东行教学中锁定其它方向和直接点击海图改航向。可选事件允许点击任意可用选项或略过，不强制跳过；打捞仍支付正常时间和补给、获得正常收益。缺少船员的选项不会被强行启用。
- 已删除工坊编组教学、三套牌组编辑检查和确认编组按钮。没有新航海士事件完成标记的旧检查点 3（工坊）/4（再次出航），保留旧版直接挑战首领的恢复路径；当前新存档须完成第二次航程的职业事件后，才从检查点 3 进入首领航程。迁移不会清空原有牌组、重复招募或授予奖励；已完成教学的存档不重新锁定。
- 按港口检查点保存；没有另外加入航行中存档。航行中退出后从该次出航前的港口快照重试，不保留未结算的收益，也不重复发放首胜奖励。
- 教学失败或未完成就返港时，开放正常后勤采购和仓库物资出售。首领战重试直接返回出航码头，继续使用默认牌组，无须编组。金币、物资及损失仍遵守普通规则。
- 若当前补给不足以继续航行、处理强制事件，或在接舷前支付撤退消耗，允许走正常返航／应急撤离流程；应急撤离按失败保护率保留 35% 收益。可选事件的略过仍使用普通规则。这不会补满资源或直接完成当前教学。
- 航海士事件的职业选项若无法支付消耗，可选择「保留笔记，返港整备」。该选项不解读暗标、不发放职业事件报酬、不视作抵达新港，也不解锁首领航程；按普通返航／拖带规则结算，确认后保持检查点 2，补给后重新完成航海士事件。

当前新手控制器依次使用初航模板 1、`CoreGuidedTutorialContent.NavigatorVoyageLeg = 2` 和 `CoreGuidedTutorialContent.BossVoyageLeg = 3`。旧版直接进入首领的两航程存档仍保留兼容恢复路径。
