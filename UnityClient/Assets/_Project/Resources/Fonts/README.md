# 碎帆纪元 · 游戏内字体

香萃刻宋（Xiangcui Kesong），作者 Miiiller，来自官方仓库 https://github.com/Miiiller/Xiangcui-Kesong 。

此字体用于匹配用户提供的尖角、木刻、复古中文参考。不是对参考图原字体身份的认定。完整字体随项目打包，运行时不依赖玩家电脑安装字体。

字体以 SIL Open Font License 1.1 发布，随包保留原始授权文件。TTF 字体内容不作修改；英文化文件名仅用于稳定的 Unity Resources 路径，不改内部字族名。

## 使用约定

`GameTypography` 统一提供字体，主菜单、教程、核心玩法和编辑器预览共用。保持字形原生字重，不额外使用伪粗体或伪斜体；标题靠字号、颜色和布局形成层级。卡牌标题也使用金色而非 `<b>`，避免小字糊成一团。

这是共享的 Resources 资源，调用方不得 Destroy。字体导入启用动态字库并包含原字体数据，玩家无需安装系统字体。字体缺失时会明确报错，内置备用字体仅用于错误诊断，不属于正常外观。

可使用 `tools/audit_typography_cmap.py` 只读检查项目文本覆盖；字体支持 31,170 个码点，当前角色故事、部件 CSV 和 Runtime 字串中的汉字均有覆盖。首领点标记使用“首”，不依赖字体不包含的交叉刀剑符号。
