## 使用约定

`GameTypography` 统一提供字体，主菜单、教程、核心玩法和编辑器预览共用。保持字形原生字重，不额外使用伪粗体或伪斜体；标题靠字号、颜色和布局形成层级。

卡牌名称由 `CardFaceLayout.FitName` 明确选择香萃刻宋，不受普通界面标题的字号阈值影响。`CardRibbonTitleEffect` 按一体卡框名称纸带的浅弧逐字调整位置与旋转，名称及强化后缀一起居中；保留字形比例和各体系墨色，不使用伪斜体。弧线参数存于 `CardSchools/Frames/Integrated/frame-layouts` 对应的边框记录，按实际旋转后顶点约束字号，使长名称仍落在纸带内。正文继续使用 `GameTypography.BodyFont`，名称和正文的布局范围独立。

卡牌正文以 16 逻辑字号为共同上限，阅读区域固定为 176×94。`CardDescriptionText` 只精简显示措辞与分行，保留 Core 的数值、条件、时序和资源规则；按实际字体宽度保持数字、单位及机制词完整，避免段尾标点单独占行。较长描述逐号缩小，标题和图窗不会随之改变。各强化等级分别统计是否至少 90% 使用共同字号，不能仅用原等级或合并比例代替。

这是共享的 Resources 资源，调用方不得 Destroy。字体导入启用动态字库并包含原字体数据，玩家无需安装系统字体。字体缺失时会明确报错，内置备用字体仅用于错误诊断，不属于正常外观。

可使用 `tools/audit_typography_cmap.py` 只读检查项目文本覆盖；字体支持 31,170 个码点，当前角色故事、部件 CSV 和 Runtime 字串中的汉字均有覆盖。首领点标记使用“首”，不依赖字体不包含的交叉刀剑符号。
