发行版本：0.3.20261016.3
状态：Release04 完整测试、快照验证、Windows 正式构建、玩家包烟测、ZIP 校验及发布封存全部通过。

范围与归属
本轮检查以工作区已有游戏内容和规则为基础。开始时工作树已有大量用户改动；已有战术棋盘、拖动航线、冲撞自动接舷、探索和寻宝内容等，不归因于本轮结构优化。保留现有工作，不以 Git 当前全部差异代表本轮新增。
本轮聚焦三项结构重构、检查发现的文案与界面问题、测试前提适配及发布证据绑定。没有进行整体性能基准，不以代码整理推断帧率、内存或加载速度改善。

三项结构重构
1. Unity 生命周期集中。
   新增 Presentation/Runtime/CoreGameplayLifecycle.cs，将 CoreGameplayDemoController 的 Awake、OnEnable、Update、OnApplicationPause、OnDisable、OnDestroy 六个入口集中到同一 partial 文件，保持原方法体与调用顺序。生成的视觉资源释放逻辑归入 CoreGameplayResourceMemory.cs。仍使用原控制器类型和现有场景、预制体引用，功能逻辑保留在各自文件。
2. 市场基础物品映射统一。
   Core/Runtime/CoreVoyageSession.cs 的五处市场物品映射改用 CoreWarehouseItemCatalog 的基础物品定义，集中维护对应关系。保留键规范化、帆布的市场显示名及不支持物品的原有处理。仓库独有的宝物、遗物和稀有货物不会因此自动成为普通市场补给。
3. 桌面构建公共逻辑统一。
   WindowsReleaseBuilder 与 MacReleaseBuilder 保留原公共批处理入口，共享 DesktopReleaseBuilder。场景清单、资源元数据检查、生产存档身份、构建选项、报告和 PlayerSettings 保存/恢复集中维护；macOS 架构设置也在 finally 中恢复。
   发布版本通过 -releaseVersion 显式传入，旧调用省略参数时保留历史默认值。拒绝无效/重复参数、非绝对输出路径和会覆盖已有产物的输出位置。发布脚本不再通过替换 C# 版本字符串出包。

检查发现并修复的实际文案与界面问题
海战行动点文案转换在正则边界中加入中英文冒号，避免转换移动描述时吞掉“木板不足，仅基础效果：”等前置说明。
CardDescriptionText 在保持效果含义和数值的前提下压缩长说明，将“每回合一次”等限定与所属效果保持关联；CardFaceLayout 加粗棋盘接舷的“相邻且同向”等使用前提。现役 319 张卡的四个等级参与卡面显示检查，保留既有字号、完整显示和可读率超过 90% 的验收门槛，不靠降低门槛消除失败。
海战行动按钮接入 WoodButtonSkin；探索状态文字行距统一为 1，修正当前布局中的显示问题。这些修复不将用户已有的战术棋盘或行动点玩法重新计作本轮功能。

测试夹具为何调整
旧规则前提：新教程 Boss 需要完成规定引导阶段，海战需要满足当前行动点、接近、射程、朝向和接舷条件。旧测试中直接进入最终奖励、使用退役移动按钮或假定旧攻击距离的准备步骤，改为符合现行规则的前提。仍验证实际奖励、伤害、资源消耗和战斗状态，不通过修改业务数值迁就旧断言。
新寻宝内容：新出航会采用当前内容版本，不能继续假定旧种子一定生成旧事件。当前版本奖励测试补齐营地、绞盘、钟声、清单/证人或昼夜线索等对应前置。海图隐藏信息测试使用明确的船内事件夹具，继续断言节点、标签和图标均不披露，并保留导航员招聘、种子入口与出航的真实界面验证。
海图复用：同一种子的新航次会从该航线的候选首领中独立抽选，不能要求两个新航次的首领 ID 必定相同。海图测试保留地形、坐标与普通事件的一致性检查，并在同一航程保存/恢复时严格核对首领和事件 ID，区分海图复用与航程恢复。
旧存档兼容：旧雾钟、诅咒奖励场景使用已出航的内容版本 0 航程检查点，经 JSON 往返和正式恢复入口加载；不把新出航强行视作旧版本，也不直接注入待验证奖励。继续验证选择、归港、货物入库、收益及重载。退役卡牌别名按现有映射从 12 转为 11，保留同卡上限与最低十张卡组的精确断言；保存日志清单补入已有仓库收益键，继续逐项检查键名排序与原生类型。
真实界面：补齐流派解锁通知的实际确认、当前面板入口、展开库存等交互前提；出航返回说明匹配六港当前统一文案。首次贸易从真实教学结束后的所在港口与资产出发，按实际补给、货舱、报价和购买额度准备航行，不硬编码旧教学终点。
现有首次制图寻宝长流程仍允许通过真实 F10 操作补金作测试准备，因此其通过仅验证该准备条件下的实际界面与奖励流程，不能作为“零 GM 辅助也能完成新手经济进程”的证据。独立的无 GM 经济专项属于下列需另行启用的检查。
