## 体系特权

六张传奇仪器牌打出后激活持续能力，消耗 2 能量并抽 1 张。能力持续到本场海战结束或进入接舷阶段，同类不叠加；重复激活不重置本回合额度。激活牌本身不占首张额度，激活前本回合已成功打出的同系牌计入首张。未成功出牌、取消选区、资源不足均不消耗额度。每个新的己方回合刷新额度。

| 体系 | 持续效果 |
| --- | --- |
| 火焰 | 每回合首张其他火焰牌结算后点燃敌舰：3 伤害，持续 2 回合；沿用燃烧取高及持续时间规则。 |
| 秘术 | 每回合首张其他秘术牌结算后恢复 1 法力，不超过上限；不能预支该法力支付本张牌。 |
| 诅咒 | 每回合首张其他诅咒牌结算后追加 1 咒印，最多增至 6 层，持续至少 2 回合；每层伤害至少 2，不降低已有更强咒印。 |
| 潮汐 | 每回合首张其他潮汐牌结算后直接获得 3 潮势，不超过上限；沿用回合结束潮势清空规则。 |
| 雷霆 | 每回合首张其他雷霆攻击结算后额外获得 1 连锁，不超过上限；非攻击牌不占该额度。 |
| 血契 | 每回合首张其他血契牌免生命成本，覆盖献血攻击、献血护盾、血誓阵与其他海战血契牌；能量与耗材照常支付。若首张本来不耗生命，仍会使用首张额度。 |

这些是出牌激活的能力；仅装备对应部件、尚未打出该特殊牌时，不会自动激活。状态栏显示待触发／已用；血契免费时，卡面费用和实际支付同步显示为 0。

下表均为 +0。所有牌的独立成长曲线、强化上限、分阶段逐级完整效果见 [逐卡强化设计](CardUpgradeDesign20261017.md)。六项持续特权的数值与触发次数固定，不随强化增长；这六张牌的抽牌维持 +0 抽 1 张、+1 抽 2 张、+2 抽 3 张，上限为 +2。
