## 史诗与传说部件的场地联动

六系各有 5 张史诗和 5 张传说部件牌，共 60 张。火焰、秘术、诅咒、潮汐、雷霆、血契分别联动己方火场、折射阵、禁域、定向水流、雷栅、血誓阵。

| 部位 | 场地联动 |
| --- | --- |
| 船首 | 攻击并向相邻空格扩展己方本系场地。 |
| 船帆 | 获得行动点，并延长己方本系场地的持续时间。 |
| 火炮 | 攻击位于己方本系场地上的敌舰时提高伤害。 |
| 船甲 | 位于己方本系场地时额外获得格挡；火焰、诅咒、潮汐、雷霆提供本系场地免疫，秘术恢复法力，血契修复船体。 |
| 史诗仪器 | 根据己舰或敌舰是否位于己方本系场地，获得本系收益。 |
| 传说仪器 | 立即扩展并延长己方本系场地，同时抽牌。 |

扩场作用于己舰 4 格内的己方本系场地，优先向敌舰方向扩展到没有场地和船只的相邻格；新增格同样须在 4 格内，并继承原场地的持续时间和水流方向。延时作用于至少有一格在 4 格内的整处己方本系场地。场地不存在时仍可使用卡牌，但不获得对应场地收益。

下表均为 +0。所有牌的独立成长曲线、强化上限、分阶段逐级完整效果见 [逐卡强化设计](CardUpgradeDesign20261017.md)。传说仪器的延时固定为 2 回合，扩场格数与抽牌随强化成长。
