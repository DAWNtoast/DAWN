## 分项规则

- 0–1 费牌的抽牌、行动能量恢复效果最多提升 1 阶；2 费最多提升 2 阶。每阶在原效果上加 1。以该阶段印刷基础费用分类，不使用临时减费或同名加价。
- 伤害、格挡、治疗以及已设计为可成长的灼烧、减伤、反击等数值仍可到 +3，倍率依次为 1 / 1.2 / 1.5 / 2，四舍五入。复合牌只封顶抽牌/回能部分，其他效果继续成长。
- 纯抽牌/回能牌整卡上限跟随其效果；纯固定功能牌为 +0。多阶段同一 ID 的整卡上限取各阶段所需最大值，各阶段效果独立封顶。
- 魔力、咒痕、潮势、连锁等系别资源，资源费用、触发条件、次数、时长、选择范围和条件额外奖励不会因为抽牌/回能强化而增加。
- 原有高阶购买记录与来源经验保留，读取时按新上限封顶有效值；不把已保存记录删除或重写为较低阶。船员/部件来源仍随航行经验成长。

- 数值取整后，整卡上限停在所有效果最后一次实际增长的等级，裁掉末尾无变化的阶级。例如基础 1 的成长为 1 / 1 / 2 / 2，只需 +2；基础 2 的 2 / 2 / 3 / 4 仍需 +3。中间的取整平台不跳级，旧记录仍完整保留。

CSV 每行对应 ID × 阶段 × 等级 0..整卡上限。AuthoredDamage/Block/Repair 是卡定义中的基础数值；系别条件、延迟、灼烧、反击和资源公式见 Description/School 字段，不将静态 0 误读为没有效果。Draw 包含 SchoolEffect.Power 型抽牌；PrintedDraw 单列原字段。雷云搜寻的条件额外 1 张独立列示。抽牌仍受手牌上限与可用牌数限制。
