# 战斗奖励与夺船收益调整 · 2026-10-15

所有战斗胜利的占舱物资奖励现已折为金币。接舷夺船获得击沉结算金币的两倍，并保留额外部件掉落机会；声望按两倍基础值沿用原整数缩放。海战与接舷的伤害、生命和固定行动循环见 [接舷难度校准](BoardingEnemyBalance20261015.md)。

## 金币结算顺序

1. 合计普通战斗基础 45 金币或 Boss 基础 120 金币、选项中的正金币奖励，以及全部正物资奖励的固定估值。
2. 潜水员先对正木材、铁矿各增加 `max(1, 数量 / 4 向下取整)`，再按固定单价折金。船医不会增加正药品奖励；负药品成本仍按原规则取 `ceil(原成本 × 75%)`。
3. 总额乘当前海图收益倍率，再按百位四舍五入，恰好半百向上取整。乘倍率后仍为正值时最低 100；倍率为 0 时为 0。
4. 夺船最后把这笔整百金币乘 2。负金币、负物资、船体损伤和士气成本在入战时照常支付，不折价、不乘奖励倍率。

例如路线 Boss 的基础总额为 `120 + 180 = 300`：倍率 1 时击沉 300／夺船 600；倍率 0.5 时先得到 150、取整为 200，最终击沉 200／夺船 400；倍率 0.25 时击沉 100／夺船 200。

声望不做整百取整：普通基础 6／Boss 基础 18，加选项正声望后，夺船先乘 2，再乘海图倍率并向下取整。因此倍率 0.25 的路线 Boss 声望为击沉 9／夺船 19。额外 Boss 碎片判定、选择项内碎片和藏宝线索沿用原规则，不纳入金币折价；教学保底碎片与返港教学奖励也保留。

## 夺船部件

炮击击沉不触发这两次部件判定。夺船的基础部件掉率为 `50% × 海图收益倍率`；成功后品质为稀有 50%、史诗 40%、传说 10%。品质概率是条件概率，不是每场战斗直接掉落概率。

具有真实装配表的 Boss 独立再判定一次 `50% × 海图收益倍率`，成功后从该 Boss 的 `ComponentIds` 取一件：路线 Boss 为史诗，传奇战舰为传说。两次都成功时可获得两件。教学首领和守藏舰没有装配表，不生成额外 Boss 装配奖励；仍可进行普通夺船部件判定。

## 文案与验证

战斗选项分别显示击沉与夺船的实际金币、声望，读取当前海图倍率和船员能力。需要时另列入战负成本、船体和士气变化、情报、藏宝线索、诅咒、碎片、线索门槛及航道解锁。正物资只计入现金；船型、船员、天气等条件继续由原条件摘要显示。仅较长的战斗选项会增加按钮行高，原选项滚动区域保持。

- [最终 Core 回归](../Artifacts/BoardingEnemyBalance20261015/BoardingRewardsFinalRegression/results.xml)：1,853／1,853 例通过，0 失败、0 跳过。包含医生药耗、15 种正物资不再显示实物、零倍率保留成本／线索／诅咒，以及原碎片缩放的文案边界覆盖。
- 最终 Core、Content、Presentation、Edit、Play 五个程序集编译全部通过；审查了 154 个遭遇变体、117 个唯一 ID、429 个选项和 32 个入战入口。
