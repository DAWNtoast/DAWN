# 逐卡强化设计（2026-10-17）

本表由当前 Core 运行时导出：每张现役可见牌使用 `GetBattleCardAtLevel` 获取 +0 至独立上限的实际定义；接舷阶段再经过 `CoreBoardingCardCatalog.ForBoarding`。同一身份的不同阶段分别显示完整 `Description`，相同描述合并阶段标签。这里只展示基础卡面；实战临时增减伤、减费、手牌与资源上限仍按战斗状态结算。

每张牌拥有独立成长曲线和强化上限，定位说明与曲线都按该牌身份配置。纯固定功能牌上限为 +0；费用、系别资源生成与消耗、触发条件、次数、持续时间和范围保持原规则。伤害、格挡、治疗与机制收益按各牌曲线成长；抽牌、回能和海战行动点（AP）的获得量分别按逐卡配置的整数增量成长，并非所有卡牌都增加这些收益。

同类部件按可比较的主要效果贡献，在相同强化等级（较低上限按其上限封顶）及各自满级保留品质成长优势。机制不同的牌，例如施加咒印与引爆咒印、献血攻击与吸血攻击，不能据此宣称逐字段支配；费用、条件和用途仍需一起考虑。船员允许低初始值、较高成长的定位在特定效果上反超，示例见下表。

内部 ID、历史卡库索引、已有强化记录与船员／部件来源经验均保持不变；有效等级读取时按该牌上限封顶，不删除原记录。编号见 [卡牌编号与顺序](CardCatalog20261017.md)，特殊机制见 [特殊卡牌重设计](SpecialCardRedesign20261017.md)。六张传奇仪器的持续特权固定，只有抽牌按 +0／+1／+2 = 1／2／3 成长。

`—` 表示超过该牌上限，不存在该强化档。表内原始换行保留为分行，所有数值直接来自当前运行时，未手工重写效果。
