# 纵火登船规则与现有系统改造方案

日期：2026-10-14。状态：设计提案，未接入游戏。

本方案将火焰体系的主要收益放在打开登船通道、迫使守军调位和维持局部优势上。船员承担主要进攻，火场同时威胁守军和登船队；灭火因此既是防守手段，也是保住己方突击力量的选择。

本轮交付规则和改造方案。下文分别标明用户设计稿已有规则、建议用于原型的补充规则，以及正式接入航程前需要确定的产品决策。30 点船体、船员身材及卡牌费用均为测试标尺，不代表已修改正式数值。现有游戏策划基线仍描述当前玩法。

## 第一轮范围

先建立两船各三区域的接舷战场，提供部署、近战、调位、登船和基础灭火，再加入 8 张核心牌。初次原型直接从两舰已接舷开始，使用独立测试配置，不连接航程奖励、人员永久损失或正式卡组存档。

原型应同时支持己方登船、敌方反登船，以及双方在同一区域交战。只让玩家烧敌舰、让敌人沿用总血量攻击，会漏掉纵火方防线薄弱这一项关键代价。

完整 14 张牌保留为后续扩展。首轮不加入无限叠烧、火伤产费或抽牌、自动全图蔓延、全队火免；也不需要先重做全部卡图。美术使用现有资源或占位表现，先验证可读性和决策。

## 与当前系统的差异

以下是 2026-10-14 工作区代码的现状；路径和入口索引见文末。

| 项目 | 当前实现 | 新方案需要 |
| --- | --- | --- |
| 接舷战场 | 双方各有总船员生命和格挡，人物立绘按名册展示 | 独立船员、当前所在船只、区域、攻血和行动状态 |
| 出牌目标 | `PlayCard(int handIndex)` 根据阶段扣敌船体或总船员生命 | 显式选择区域、船员、移动落点，并处理可选目标 |
| 登船 | `TryBoard()` 让整场战斗切入接舷阶段 | 区分舰船建立连接与单个船员跨船移动 |
| 火焰 | 全敌方单一状态，持续伤害取较强值，可延长至最多 3 次 | 每区独立，固定 1 点区域伤害，重复点燃刷新至 2 次 |
| 燃烧时点 | 玩家结束回合，先结算敌方燃烧，再执行敌方行动 | 在区域所属船只的船长回合末结算，守军先有行动窗口 |
| 攻击与移动 | 没有单位攻击次数，接舷主要通过出牌扣血 | 每名船员有自己的行动资格，移动不随意刷新攻击 |
| 胜负 | 船体或接舷总生命归零会触发胜负 | 明确单位死亡、船体击沉与未来夺船条件的关系 |
| 费用 | 基础每回合 3 点，不自然增长；同一 ID 的牌本回合每成功使用一次，后续副本费用 +1；另有临时回费牌 | 明确新模式费用与同名递增策略，不能直接继承旧报价 |
| 卡组 | 当前代码为每阶段 10～20 张基础牌，同名最多 2 张 | 首轮测试牌组独立配置，正式扩充保留历史卡牌身份 |

当前普通船员对应的接舷最大生命为 `20 + 普通水手人数 × 4`；接舷卡牌的人数缩放在当前代码中固定为 1。根目录旧策划中的部分卡组大小和人数缩放说明已落后于实现，本次不据此改动正式数值。

## 设计稿已有规则

### 战场和局部防守

每艘船分为船首、船中、船尾，对位区域之间可以登船。单位控制者与其所在船只的所有者必须分别记录：我方船员登上敌舰后，仍由我方控制，但承受敌舰所在区域的燃烧。

船员在同一区域交战。登上敌船后，只有当地没有敌方守军，才能攻击该船船体。守军退到其他区域，会让出原区域的船体攻击通道。

### 浸油和区域燃烧

| 状态 | 载体 | 结算规则 |
| --- | --- | --- |
| 浸油 | 单个船员 | 下一次受到火焰伤害时，该次伤害额外 +2，随后移除；不能叠加 |
| 区域燃烧 | 一艘船的一个区域 | 初始剩余 2 次；该船船长回合结束时，区域内所有船员及该船船体各受 1 点火焰伤害，再减 1 次 |

重复点燃只刷新为 2 次，不增加每次伤害。火焰不自动蔓延；蔓延必须来自卡牌。多个燃烧区域各自伤害船体，因此三处同时燃烧时，一次该船回合末结算合计造成 3 点船体伤害。

燃烧不分敌我，按区域所在船只的回合计时，不按船员控制者计时。我方回合登上敌船火场后，敌方先行动，再在敌方回合末烧伤该处双方船员。

完全免疫优先于浸油。湿帆护卫免疫区域燃烧结算时，不触发也不消耗浸油；直接火焰攻击仍能伤害它，并正常触发浸油。

燃烧标记中的数字表示剩余结算次数。界面应写明“剩余 2 次”，并单独说明“每次 1 点”；浸油标记跟随船员，火场标记留在甲板。

### 三种公共对策

每艘船每回合可进行一次基础灭火：一名己方船员放弃攻击机会，扑灭自己所在区域。调位让守军止损，但会让出原区域；反登船则利用纵火方花费卡牌和费用铺设火场时的防守空隙。

灭火不依赖抽到克制牌。公共卡池可以提供少量清油或灭火能力，但首轮不加入廉价全船灭火，以免一个动作否定整个体系。

## 建议的原型补充规则

本节补齐设计稿未限定的运行细节，供第一轮原型采用；不是已确定的正式游戏规则。

### 区域容量与部署

船首与船中相邻，船中与船尾相邻，船首与船尾不直接相邻。每区每方各有 2 个船员位，允许双方混驻；守军占满自己的位置，不会直接禁止对方登船。普通移动和强制调位都检查移动者所属方的空位。

船员只部署到己船的合法空位，即使该区域已有敌人，也可部署增援。新部署船员本回合没有行动资格，但部署效果立即生效。焦油搬运工在没有敌方船员时仍可部署，浸油部分跳过；这是保证基础牌不因缺少目标而停摆的补充约定。

原型中的单位是测试战斗实体，不自动等于航程中的一名普通水手或具名角色。部署牌成功使用后关联该单位并退出抽弃循环；单位倒下后，该牌本局移出，避免通过洗牌不断复制同一批船员。战术牌进入弃牌堆；双方首轮各抽 5 张，之后回合末弃手牌，下个己方回合再抽 5 张，牌堆不足时洗入弃牌堆。首轮不增加疲劳伤害，长局以测试未结束记录，不伪判胜负。

### 行动和近战

每名存活船员在其控制者回合开始获得 1 次行动。该行动与打牌费用分开记录。

| 操作 | 单位行动消耗 | 约束 |
| --- | --- | --- |
| 普通调位 | 1 次 | 只能到同船相邻区域 |
| 普通登船或返回本船 | 1 次 | 两舰已连接，只能跨到另一艘船的对位区域 |
| 攻击船员 | 1 次 | 目标为同区域敌方船员 |
| 攻击船体 | 1 次 | 自己在敌船，且当地没有敌方守军 |
| 基础灭火 | 1 次 | 己方回合、己船上的己方船员、当前区域燃烧，本船本回合尚未灭火 |
| 战术引发的移动 | 不消耗、不恢复 | 保留移动前的行动状态，并检查卡牌要求和落点 |

普通移动与攻击共用行动，使“趁焰登舷”能够保留尚未使用的进攻机会。已攻击船员、新部署船员虽可被战术移动，却不会因此获得攻击资格。已用过行动的船员也不能再基础灭火。

近战双方同时造成各自攻击力的伤害，反击不消耗防守者的行动，也不因防守者已经行动而失效。攻击船体不受反击。击败守军后没有伤害溢出到船体，也没有额外攻击；可以由另一名尚未行动的登船者继续进攻。

单位生命归零后移出战场。首轮使用船体归零判负，同批双方船体归零判平；暂时全无船员不会自动判负，因为仍可能部署后备。正式“夺船”条件单独设计，不继续以旧总船员血池归零代替。

### 选择和效果时序

烟焰驱赶由受影响船员的控制者选择承受 2 点火伤，或移动到具体的合法同船邻区。存在多个落点时，落点也由防守方选；无合法落点才强制承伤。选择期间暂停后续操作，不能趁机出牌、攻击或结束回合。敌方使用该牌时，玩家同样获得选择窗口。

火钩突击手记录一生一次的“首次进入敌船”。第一次落点没有燃烧，也会消耗首次机会；撤回再登船不能补触发。普通登船和战术登船都可触发，触发伤害不消耗单位行动。若有多个敌方船员，由火钩控制者选择其一；落点没有敌人则跳过伤害，不将机会保留到以后。

火罐投掷先确认敌方区域和可选船员，再支付并结算；没有船员也能点燃。收火撤离先熄灭所选区域，再执行可选的同船调位；没有可移动友军时仍可灭火。原稿未明确未燃烧区域是否为合法目标，原型建议允许选择，灭火为空操作，但仍可移动友军；正式卡文须明确这一边界。

引火箭是否点燃区域，读取伤害发生前的浸油状态，并保留当时所在区域；不能在伤害消耗浸油或目标死亡后才判断。焚舰号令先记下敌船燃烧区域数量，清除这些火场，再一次性造成数量 ×3 的船体火伤，不额外触发一次自然燃烧。

### 回合和批量伤害

建议的完整回合顺序如下：

1. 回合开始：移除在该船长回合开始到期的效果，恢复该方费用和存活船员行动，重置本船灭火次数，再抽牌。
2. 行动阶段：双方按当前行动权执行命令；驱赶等效果需要的选择在命令中暂停并继续，不开启额外回合。
3. 回合结束：快照当前回合船长自己的船上所有火场及其中船员。另一艘船不在此时结算。
4. 对快照目标计算伤害：先判断伤害来源对应的免疫，再判断浸油加伤与消耗。基础近战不属于火伤。
5. 同批应用所有区域伤害、处理死亡、减少各火场剩余次数，再判胜负。已经熄灭或结束的火场不会再结算。
6. 战斗继续时交出回合。双方使用同一规则；不能让敌方火焰先于其救火行动触发。

首轮没有减伤护盾，避免引入“加油伤害后被减至零是否耗油”的额外歧义。正式加入减伤时需要补充这一规则，不能把“湿帆免疫保留油”泛化成未经定义的所有抵挡效果。

扩展前补齐三个细节：烟幕按区域动态保护当前驻留者，并禁止双方的单体战术指定；区域牌附带的可选单体目标也受限制，但不妨碍合法的区域效果。掠夺者按单位记录次数，建议只认可主动近战击杀，不认可反击、火伤或登船触发伤害。多个大副的叠加规则须在加入该牌时明确，不能顺手继承旧全局增伤。

## 数值配置和突破示例

现有每回合基础 3 行动点不能直接承接 5～6 费卡。建议第一轮规则测试固定每方 6 费，双方船体各 30，普通船员为 2 费 2 攻 3 血。原型使用固定卡面费用，暂不启用旧系统的同名牌递增；费用预览和实际支付都读取新规则。以上仅用于接舷测试，正式三阶段战斗继续现有配置。

建议首轮自由对局使用 20 张测试牌：8 张核心牌各 2 张，共 16 张，另加 4 张普通船员。普通船员副本数量属于测试配置，不改正式同名最多 2 张的限制。首轮只有火罐投掷能点燃，而牌组只有两张火罐；三处火场同时存在需要洗回并再次抽到点火牌，不能保证自然出现。三火场号令另用预置局面测试，自由对局则记录实际能否形成这一窗口。

固定突破局面使用普通 3 攻 3 血突击船员，避免火钩额外伤害混入示例：己方船中突击者尚有行动，敌方船中只有一名 2 攻 4 血守军，双方船体各 30。己方 6 费，手中有火罐投掷、烟焰驱赶和趁焰登舷。

先以 2 费火罐点燃船中并将守军打至 3 血，再用 2 费驱赶，最后用 2 费登船。两条分支如下：

| 守军选择 | 登船后的攻击 | 若敌方之后不再行动且不灭火 |
| --- | --- | --- |
| 撤到合法邻区 | 船中无人防守，突击者攻击船体 3 点，敌船剩 27 | 敌方回合末，敌船再受 1 点至 26，突击者从 3 血降至 2 |
| 留守承受 2 点火伤，剩 1 血 | 突击者近战击败守军，同时受到 2 点反击，剩 1 血；本次不能再打船体 | 敌方回合末，敌船从 30 降至 29，突击者被火烧倒 |

后半列是隔离规则的固定测试结果；实战中敌方可以增援、进攻或灭火。留守分支会用突击者换掉守军。该连招已经用尽 6 费，且原型没有额外响应窗口，不能再假定自己能在敌方回合免费救人；若要保住突击者，必须在己方回合结束前另留控火费用、改变行动顺序或放弃这次进攻。

## 操作界面和敌方行为

战场应同时呈现两艘船和各自三区域。单位卡显示攻血、所属方、可行动状态和浸油；区域显示火焰、剩余结算次数及烟幕期限；双方船体保持可见。选中登船船员时，突出其实际控制者，避免把站在敌船上的友军误认成敌人。

出牌采用“选卡、选择合法目标或区域、确认完整命令”的流程。可选效果提供明确跳过选项；提交前取消不扣费用、不消耗手牌。玩家点击的对象已失效时，重新选择或取消，不能自动改打另一目标。规则层负责合法性，界面只展示同一套结果。

驱赶窗口展示“坚守，承受 2 点火伤”及具体可撤退区域。若目标浸油，伤害预览应为 4 点；若撤退会让出船体通道，预览显示这一后果。无合法落点时说明承伤原因，不提供无效选项。

敌方首轮可用确定性启发式策略，但必须调用与玩家相同的命令和资源规则。决策至少比较：当前或即将遭受的船体致命伤、灭火能保住的船员、放弃攻击的代价、撤退后是否打开通道，以及是否能反登船。敌方不得固定选择撤退或固定选择承伤；同一固定局面应能复现其选择和战报。

动画消费结算事件：移动、点燃、伤害、死亡、灭火和选择完成。动画结束不再次修改生命或推进回合；选择窗口与动画输入锁应分别处理。

## 规则层与界面改造

### 新增独立接舷状态

建议在 Core 中增加独立的区域接舷状态和结算器，通过规则模式接入会话。下列名称为拟议职责，不代表已有代码。

| 职责 | 最小数据或能力 |
| --- | --- |
| 战场状态 | 规则版本、当前行动方、回合编号、双方船体、费用、手牌和牌堆、待处理选择、随机状态 |
| 区域状态 | 船只所有者、区域位置、燃烧剩余次数；扩展时记录烟幕到期方和时点 |
| 单位状态 | 独立单位 ID、控制者、所在船只和区域、攻血、剩余行动、浸油、区域火免疫、首次登船记录、可选角色来源 ID |
| 卡牌定义与实例 | 稳定卡牌 ID、类型、费用、目标描述、效果；部署实例关联单位，不能仅凭卡名区分同名单位 |
| 命令 | 部署、出战术、移动、攻击单位或船体、灭火、结束回合、提交驱赶等选择 |
| 事件 | 已支付、已部署、已移动、已点燃、伤害和来源、单位倒下、火场结束、待选择、战斗结束 |

命令统一执行“检查行动方和状态、检查全部目标、报价、原子支付、按时序结算、产生事件”。一条命令失败不得吞卡、费用或行动。已支付的驱赶进入待选择状态后，不允许再次支付、重复结算或绕过选择继续操作。

单位战场是新模式唯一的接舷伤害来源。旧 `PlayerBoardingHealth` 和 `EnemyBoardingHealth` 不参与新模式结算；如有过渡性总生命显示，只能由单位状态单向汇总，不能反向扣伤或触发旧胜负。

## 正式接入与存档兼容

### 卡牌身份与数据来源

历史卡组用整数索引保存，且学派牌后还有整顿号令、战术筹划。在火焰卡表中间插入新卡，会移动后续卡牌的位置。正式实施前先保存完整旧库的 `index → id` 映射；新增卡放在完整旧库末尾，或通过明确版本迁移读取旧索引。退役位置保留空槽，不让别的牌占据旧身份。

同时处理两处卡组持久化：航程存档 `CoreVoyageDeckCheckpoint.cards` 和 PlayerPrefs 中按阶段保存的整数列表。若改用稳定卡牌 ID，两处都要支持旧版本读取。特殊船员和部件卡还关联来源 ID、升级和经验，不能仅因改名或换效果就换掉这些身份。

`CoreSchoolCardCatalog.cs` 来自 `tools/CardSchools/build-catalog.cjs`。正式改卡时同步生成源和卡文模板，不能只修改生成物。该脚本的普通执行还会重写旧美术清单；如只改卡表，应使用其现有 `--catalog-only` 范围并核对输出。旧清单、提示词和可用脚本不构成外部图像 API 授权。

当前航程存档仅在航行或事件阶段、且没有进行中的战斗时保存，因此没有旧的战中区域状态需要迁移。未来若增加战中保存，需另行保存规则版本、单位、火场、费用、回合、待处理选择和随机状态，并验证恢复后不重复扣费或触发效果。

### 海战转入接舷

正式接入时可复用距离、航向、撞击和接舷转场，但初始化三区域不能直接复用旧总血量换算。需要分别确定船体损伤的保留、船员初始部署、伤势分配、火场来源，以及由哪一方先行动。

现有接舷会清空旧燃烧，特定卡牌再通过接舷种火恢复效果。新模式不得把无位置的旧全局燃烧默认复制到三个区域；建议新海战纵火效果显式选择区域，接舷后保留其剩余次数。旧全局火焰向新区域的兼容映射需单独定义，首轮接舷原型不执行该转换。

海战损伤只转换一次。若以后将原总船员伤势分配到单位，不能同时保留旧总血池扣损，再扣一次单位生命；撞击致死的船只也不能继续初始化接舷战。

### 正式落地前的产品决策

这些选择不妨碍独立原型，但决定正式游戏怎样整合。

| 决策 | 建议方向 | 首轮处理 |
| --- | --- | --- |
| 出航编制与部署牌 | 船员牌代表调遣本次随船队伍；普通水手可按小队抽象，具名角色保持唯一身份 | 使用测试单位，不扣航程人数，不解释为永久死亡 |
| 费用制度 | 单独评估接舷费用曲线、重定价及同名递增，使高费牌能自然进入计划；不靠额外回费牌掩盖问题 | 固定 6 费、固定卡面费用，仅用于规则和体验测试 |
| 船体与单位数值 | 先确定正式船体尺度，再统一换算伤害、火伤和成长，避免 1 点火对高耐久舰船失去作用 | 30 船体、普通 2 费 2 攻 3 血，无强化或士气暴击 |
| 船员倒下与夺船 | 区分本场失去战斗力、航程减员和角色永久死亡；另定俘获与击沉的收益 | 单位倒下移出本局，船体归零判负 |
| 旧卡池与其他学派 | 对旧直伤、治疗、格挡逐张指定新目标和范围；区域、移动和灭火作为所有体系的公共规则 | 仅用 8 核心牌和普通船员 |
| 跨阶段火场 | 新纵火效果保留区域身份；旧全局火焰采用显式兼容规则 | 直接从已接舷、未燃烧或预置火场的测试局面开始 |

## 实施顺序与验收

| 阶段 | 内容 | 完成标准 |
| --- | --- | --- |
| 一 | 纯规则状态、行动、部署、近战、局部防守、基础灭火 | 不依赖界面可重放固定命令，双方规则一致 |
| 二 | 区域火焰、浸油、8 核心牌、待选择状态 | 下列规则场景全部通过，失败命令不消耗资源 |
| 三 | 六区域交互界面、战报和敌方策略 | 玩家能识别控制者、火场时点及合法落点，能完成双方驱赶选择 |
| 四 | 自由对局与平衡记录 | 玩家因火场改变路线、行动顺序或撤离时机；确认点火、救火和反攻都有作用 |
| 五 | 正式迁移 | 确定编制、费用、胜负与跨阶段映射，完成卡组和来源兼容后接入航程 |
| 六 | 扩展其余 6 张牌 | 已能稳定验证基本登船循环，再增加烟幕、资源和蔓延组合 |

### 规则验收场景

| 场景 | 预期结果 |
| --- | --- |
| 六费突破的撤退与留守分支 | 分别打开船体通道与消耗一次攻击清理守军；没有伤害穿透 |
| 敌船火场中有双方船员 | 我方回合末不结算该火场；敌方回合末伤害双方驻留船员和敌船 |
| 重复点燃与多区燃烧 | 同区只刷新至 2 次；三火场各 1 点，总计船体 3 点，无自动蔓延 |
| 浸油普通船员与湿帆护卫 | 区域伤害分别为 3 并清油、0 并留油；后者受到直接火伤仍加 2 并清油 |
| 趁焰移动未行动、已行动和新部署船员 | 只有原先尚能行动者可继续攻击，不额外发放行动 |
| 基础灭火后再次尝试 | 消耗该船员行动和本船次数；其他船员不能再次基础灭火，卡牌灭火另按效果处理 |
| 区域两名守军与退路占满 | 敌方仍可使用自己一方空位登船；驱赶无合法退路时只能承伤 |
| 船中空、船首有守军 | 船中登船者可攻击船体，船首守军不隔区阻挡 |
| 近战同归于尽 | 双方伤害均生效，再统一移除单位；无剩余伤害转打船体 |
| 火钩首次进入无火区，再次进入火场 | 第二次不补触发；第一次直接进入火场则正常触发 |
| 收火撤离 | 先灭火，可跳过移动；移动仅限同船邻区，保留行动状态，不自动回己船 |
| 三处火场使用号令 | 敌船体受 9 点，全部火场清除，无额外自然结算，后续火场条件失效 |
| 非法目标、取消和重复提交选择 | 提交前失败不扣资源；待选择期间不允许其他命令；重复选择不重复执行 |
| 敌方反登船 | 与玩家使用同一容量、行动和当地守军规则，能威胁纵火方船体 |
| 部署牌循环 | 在场或已倒下单位对应的牌不重新洗入手牌生成副本 |

自由对局记录以决策为主：点火位置、登船落点、驱赶分支、基础灭火牺牲的攻击、主动控火保住的船员、友军烧伤与反登船机会。伤害来源分为船员攻击、区域火、战术火伤和号令，检查主要进攻是否仍由船员完成。

这些是待执行的验收项，不是本轮已跑出的测试结果。本轮只有方案文档，不运行 Unity 构建、卡表生成器或场景同步；后续验证不恢复或更新已退役的 `Scenes/UIPreviewsForMe`。
