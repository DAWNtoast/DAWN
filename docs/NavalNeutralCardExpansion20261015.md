# 海战通用卡牌扩展设计

本方案以当前行动点海战为基础，组成 32 张通用卡的候选卡池：新增 21 张，将「迎敌推进」调整为 0 费获得 1 行动点，沿用现有卡 10 张。覆盖抽牌、船体回复、格挡、回能、装弹、炮击、行动点，以及这些效果的组合。表中均为未强化数值；本文件是设计稿，新增候选尚未写入运行时卡库。

所有卡均为中立海战牌，不需要特殊船员或部件，不产生或消耗火焰、秘术、诅咒、潮汐、雷霆、血契的专属资源。通用炮击仍可正常承接已有装备和学派赋予的增益。

## 费用和行动点基准

| 印刷费用 | 纯行动牌获得行动点 | 角色 |
|---:|---:|---|
| 0 | 1 | 补足移动后的接舷或再次移动需求 |
| 1 | 2 | 日常调整航线 |
| 2 | 5 | 绕行和大幅调整站位 |
| 3 | 8 | 一次远距离航行，占用整回合自然能量 |

这里的费用支付能量；行动点用于航行及接触指令。1／2／5／8 是纯行动牌的精确收益曲线，其他类型以此作效率参考，再结合现有基础牌定价。复合牌获得的行动点低于同费纯行动牌，用减少的机动能力交换其他收益；抽牌、回能不能机械按 1／2／5／8 等量兑换。

当前每回合基础为 3 能量、1 行动点；每格 100 米。表中行动点均为增加量，例如回合开始直接打出极限航行后共有 9 点，可以规划最多 9 格。确认一次移动后，全部行动点清空，包括未走完的额度，不能把剩余额度保留给下一次独立移动。行动牌只增加点数，不自动改变位置或朝向。普通炮击出牌本身不另耗行动点。

复合卡不自动移动。玩家先打出卡，再自行规划航线、确认移动与到达朝向。「射后转进」必须出牌时已经在炮击射程内，不能用它先获得行动点进入射程再开炮。「满帆转向」「拉开距离」的名称不改变上述规则。

轮班调度第一次使用先支付 2 能量，再恢复 1，净消耗 1；全舰协同先支付 3，再恢复 1，净消耗 2。两者都不能在支付能力不足时靠本牌的回能启动。此净消耗仅对应未强化、当回合首次使用。

## 物资和结算规则

1. **可用阶段。** 含炮击的卡仅用于炮战；其余卡用于准备阶段和炮战。新卡均不加入接舷牌组。沿用的跨阶段 ID 保持各自接舷定义，不能因海战设计覆盖接舷效果。
2. **抽牌。** 抽当前阶段牌。手牌上限 8，溢出的抽牌次数不转成别的收益。牌库为空时沿用弃牌洗回机制。
3. **回复。** 修复船体，不回复船员生命，不超过最大船体。沿用现行木板机制：有木板且缺失船体超过 2 时，本次有效修复消耗 1 木板；无木板最多修复 2。基础修复只有 2 的堵漏木楔不耗木板；满船体或只缺 1～2 时也不耗木板。若强化使堵漏木楔的修复超过 2，同样按木板规则结算。
4. **格挡。** 沿用船体格挡及已有防御增益。准备阶段格挡带入首轮炮战，正常回合按现有规则清除。
5. **装弹。** 表中的装弹指给下一次炮击增加伤害，不制造火药或炮弹库存。本批装填累计上限仍为 12；不足额度时只加剩余额度，不降低已经存在的更高增益。每次装填牌消耗 1 火药，开炮另外支付 1 火药和 1 炮弹。炮击后清空装填增益；复合牌在装填已满时仍可结算其他有效效果。
6. **炮击。** 出牌时射程不超过 4 格，按两舰横向格数与纵向格数之和计算，不按实际直线距离判断。右 3 格、上 2 格合计 5 格，不能炮击；右 2 格、上 2 格合计 4 格，可以炮击。每张炮击卡支付 1 火药和 1 炮弹。表内为卡牌基础伤害，实际还叠加现有火炮性能、装填及其他适用增益，并走现有防御结算。每张均为一次炮击，不能按名字理解成额外的多段攻击。
7. **能量。** 回能可临时超过基础 3 能量，沿用回合开始重置规则；不增加行动点。纯回能只保留整顿号令这一来源，其余新增回能放入在 +0 时有实际净消耗的复合牌。
8. **同名加价。** 所有卡都沿用同一稳定 ID 当回合每成功使用一次，后续费用 +1；副本共享计数，下一回合重置。例如 +0 迎敌推进依次为 0／1／2 费，每次获得 1 行动点；强化后的行动点收益读取该牌对应等级，重复出牌的临时加价不会增加收益。1／2／5／8 按印刷费用定义，不因临时加价增加效果。

## 强化和卡池接入

表内只给出 +0 基础值。2026-10-17 起，强化规则采用[逐卡强化设计](CardUpgradeDesign20261017.md)：每张牌分别配置成长幅度、抽牌／回能／行动点增量和最高等级，不再统一使用倍率或按费用决定上限。装填总上限仍为 12；每个可达强化等级均须有实际收益。

行动点获得量可随强化按逐卡配置的整数增量成长，幅度与抽牌增量同样独立设计；纯行动牌也可通过增加行动点获得有效强化。复合牌可分别成长行动点、抽牌、回能或其他数值，以当前运行时导出的逐级表为准。全舰协同、轮班调度等同时提供抽牌和回能的牌，需要连同整顿号令检查各自满级的单回合连锁长度，不能把 +0 的净消耗结论延伸至所有等级。

现有 ID 处理如下，其余新增卡只在目录末尾追加，保持存档索引稳定。

| 卡名 | 现有 ID | 处理 |
|---|---|---|
| 迎敌推进 | `card_approach` | 海战印刷费用为 0，+0／+1 分别获得 1／2 行动点，强化上限 +1；保持 ID 和同名加价规则 |
| 战术筹划 | `card_tactical_draw` | 沿用海战抽 2，保留接舷阶段定义 |
| 稳固船身 | `card_brace` | 沿用 |
| 规避机动 | `card_evasive_maneuver` | 沿用 |
| 紧急修理 | `card_emergency_repair` | 沿用 |
| 整顿号令 | `card_energy_order` | 沿用海战回能 1，保留接舷阶段定义 |
| 装填弹药 | `card_load_shot` | 沿用 |
| 链弹 | `card_chain_shot` | 沿用 |
| 炮火齐射 | `card_cannon_barrage` | 沿用 |
| 满帆转向 | `card_full_sail_turn` | 沿用当前行动点版 |
| 拉开距离 | `card_retreat` | 沿用当前行动点版 |

本表不删除未列出的旧牌，不给同效果旧牌换名再发一份。新增牌建议沿用基础卡每种 2 张、基础牌组 10～20 张的当前构筑规则；这里只确定战斗设计，不新增解锁货币或来源条件。

## 实装需要处理的事项

当前数据结构还不能直接表达全部新设计，接入时需要同时处理以下事项。

- `NavalActionPointGain` 读取卡牌的基础行动点与逐卡强化增量，支持不同卡牌在不同等级获得不同数量；卡面、预览、可用性判断和结算须共用这一结果。
- 行动点和其他效果需要独立执行。当前 `ApplyBattleCardStrategy` 在获得行动点后提前返回，会让「边航边装」的装填分支被跳过，不能只添加卡表。
- 装填量当前由动作类型固定推导为 5，需要能表示 3 和 10；新卡回能也要能与行动、格挡、修复共存，不能只依赖互斥的动作枚举。
- 强化后的卡定义、卡面预览、实际结算、出牌可用性检查应读取同一组数值；装填已满时，行动点等其他收益也应计入可用性判断。
- 新卡追加到目录末尾；已有稳定 ID 和接舷映射保持对应。迎敌推进承担 0 费档，纯行动卡新增 1／2／3 费档后，要重新核对旧纯机动牌与入门牌组是否仍有用途，不把六大体系或来源牌一起批量改值。

## 首轮平衡验证重点

这些是需要通过实际对局确认的候选数值，尚未做新卡运行时或实战验证。

| 场景 | 检查内容 |
|---|---|
| 高火力装备加仓促点射 | 零费炮击仍获得完整装备加伤和装填；检查是否把其他炮击牌挤出牌组，同时记录每场弹药消耗 |
| 整顿号令加两张回能复合牌 | 分别检查 +0 和最高强化下的出牌数量、净能量与同名加价是否正确；不同 ID 的多段连锁仍需控制节奏 |
| 5 点或 8 点行动点移动 | 路径、第一格朝向、移动后清空、到达定向，以及移动后再次获取行动点均正确 |
| 移动后接舷 | 先移动会耗尽行动点，需要到达定向后补点再接舷；新行动牌不能让旧操作限制失效 |
| 满手打出抽牌或全舰协同 | 只抽到 8 张，其他效果仍完整结算；界面显示实际抽牌数量 |
| 无木板、只缺 1～2 船体、满船体 | 保底修复、木板扣除与实际恢复分别正确，复合牌其他效果不被取消 |
| 已有装填 10 再使用压实装药 | 实际只增加 2；已有增益不被改小；开炮后按原规则清空 |
| 射程外打出射后转进 | 整张牌不可打出，不先扣费或授予行动点 |
