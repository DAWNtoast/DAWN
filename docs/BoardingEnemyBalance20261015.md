# 接舷敌方难度与固定行动（2026-10-15）

> 历史记录：本文固定行动与 14,336 场模拟对应旧版简化脚本，保留作为校准过程证据。当前 Boss 纯系别资源、多动作循环及重新校准结果见 [Boss 纯系别接舷校准](BoardingEnemyPureSchools20261015.md)。

## 校准基准

先确定玩家强化，再调整敌人。完整卡牌上限、各阶数值与来源见 [卡牌强化规则](CardUpgradeLimits20261015.md) 和 [逐卡逐阶 CSV](../outputs/balance_configs/card_upgrade_limits_20261015.csv)。

- 抽牌、回能按各阶段印刷费用独立限效：0–1 费效果最多获得一次提升，2 费最多两次；每次增加 1。临时减费、同回合重复加价不改变上限。
- 复合牌其他可成长数值继续按自身强化阶级增长；纯功能牌停在最后有收益的阶级，固定效果不开放强化。共享来源卡保留同一强化记录，各阶段分别限制效果。
- 此次敌人以这些实际效果为基准。炮战船体、炮击、防御基值保持现有配置；接舷使用独立防御基值。后续战斗奖励与夺船收益调整见 [奖励规则与新表](BoardingRewards20261015.md)。

## 敌方卡组与行动

每艘 Boss 按船只现有 `SchoolId` 选择敌方专用卡组。每回合固定出一张，四回合后从第一张重复；不洗牌，也不随战斗时长无限加攻。意图显示系别、循环位置、当前卡名、实际伤害与附加效果，并预告下一张。普通敌人为三回合循环：攻击 → 防御 → 攻击。

下表攻击、点燃、治疗、自损和吸血的百分比基于“近战基值”；格挡基于“接舷盾基值”。结果四舍五入，穿盾部分向下取整。它们是敌方专用动作，不冒用我方同名卡的数值和强化规则。

| 系别 | 第 1 回合 | 第 2 回合 | 第 3 回合 | 第 4 回合 |
|---|---|---|---|---|
| 火焰 | 引火突袭：70% 攻击；破防后点燃 15% × 2 次 | 炉卫列阵：100% 格挡 | 烈焰强攻：145% 攻击 | 持盾火刃：80% 攻击、50% 格挡 |
| 奥术 | 星轨蓄能：100% 格挡 | 秘术齐击：100% 攻击 | 月环校准：80% 格挡 | 星轨释放：165% 攻击 |
| 雷电 | 雷光试锋：75% 攻击 | 霆锋追击：100% 攻击 | 雷卫整队：80% 格挡 | 雷冠决击：150% 攻击 |
| 血誓 | 赤誓抢攻：105% 攻击、自损 15% | 血契护阵：80% 格挡 | 偿血追猎：105% 攻击、最多吸血 20% | 决死赤刃：145% 攻击、自损 20% |
| 潮汐 | 潮壁列阵：120% 格挡 | 退潮反击：80% 攻击 | 回潮援护：65% 攻击、治疗 25% | 巨浪推进：125% 攻击、50% 格挡 |
| 咒印 | 蚀魂试刃：75% 攻击，其中 25% 穿盾 | 咒卫结阵：100% 格挡 | 月蚀穿魂：125% 攻击，其中 25% 穿盾 | 咒甲压进：85% 攻击、50% 格挡 |

结算边界：格挡按当轮动作重设，不能逐轮累积；整次攻击只触发一次减伤、格挡反应和反击。穿盾不消耗被绕过的格挡。火焰命中完全被格挡时不点燃，点燃在之后两个我方回合末结算，与玩家主动自燃分开。敌方自损至少保留 1 点生命；吸血不能超过我方实际失血与敌方缺失生命；治疗不能超过上限。教学战和训练靶保留各自的原有脚本。

## 模拟与验证

采用真实 Core 的独立接舷模拟：16 种遭遇 × 7 种 14 张牌组 × 8 档舰船/强化组合 × 16 个确定性种子，共 14,336 场。牌组包含基础与六系代表性组合；实际出牌、抽牌、资源、费用、暴击、回合结算与胜负均走游戏代码。

舰船生命从真实入场记录读取：轻帆船灰鸥 60，巡防舰铜钟 108，重炮舰雷铸 132。请求强化档位对每张卡按实际上限封顶；没有专家和部件加成。药品 10、火药 30 均有限且实际消耗。决策只读取当前手牌、公开状态和敌方意图，不窥视牌库。

第一轮候选值让三档对应航线 Boss 都达到 100% 胜率，平均只用 3.39 / 3.56 / 4.12 回合，胜局剩余生命约 88% / 87% / 86%。因此增加航线 Boss 耐久并适量增加近战；传奇原本已带来明显损耗，只增加约 10–15% 耐久，保留近战基值。

最终 14,336 场全部完成，无超时。以下仅取各进度对应舰船与强化档；“请求 +N”仍逐卡按合法上限生效，绝不使 +1 / +2 封顶牌越级。

| 遭遇 / 玩家配置 | 胜局 / 样本 | 平均接舷回合 | 胜局平均剩余生命 |
|---|---:|---:|---:|
| 第一航线 / 灰鸥、未强化 | 224 / 224 | 4.26 | 76.52% |
| 第一航线 / 灰鸥、请求 +1 | 224 / 224 | 3.42 | 85.59% |
| 第二航线 / 铜钟、请求 +1 | 224 / 224 | 4.61 | 75.83% |
| 第三航线 / 铜钟、请求 +2 | 224 / 224 | 5.28 | 73.02% |
| 宝藏 / 铜钟、请求 +2 | 112 / 112 | 6.13 | 59.38% |
| 传奇 / 雷铸、请求 +2 | 670 / 672 | 7.12 | 58.30% |
| 传奇 / 雷铸、请求 +3 | 672 / 672 | 5.49 | 73.52% |

传奇 +2 的两场败局均来自代表性咒印牌组对绯刃寡妇号。不同牌组战斗长度仍有差异：爆发牌组较快，潮汐与咒印较慢；没有为追平最快牌组而继续抬高全部 Boss 的生命。完整 [逐战记录](../Artifacts/BoardingEnemyBalance20261015/FinalCalibration/runs.csv)、[分组统计](../Artifacts/BoardingEnemyBalance20261015/FinalCalibration/summary.csv) 与 [实际遭遇数值](../Artifacts/BoardingEnemyBalance20261015/FinalCalibration/encounters.csv) 可复核。

最终相关 Core 回归 **1699 通过、0 失败、0 跳过**，包含固定循环、意图与实际伤害一致、灼烧先致死取消攻击、末阶空强化、历史记录保留及原有战斗回归。结果见 [NUnit XML](../Artifacts/BoardingEnemyBalance20261015/FinalCalibratedRegressionPassed/results.xml)。Core、Content、Presentation、EditMode 和 PlayMode 测试程序集均通过本地 Unity 编译器集成编译；此处是编译与离线 Core 验证，未运行 Unity 场景内体验测试。

最后的灼烧/近战显示修复只新增真实伤害结果记录。使用最终源码另跑 896 场同种子交叉验证，与上述模拟的对应 896 场全部 19 列结果一致，未改变战斗数值；见 [比对证据](../Artifacts/BoardingEnemyBalance20261015/FinalPresentationCrosscheck/comparison.json)。

模拟限制：每场双方满血直接接舷，未计炮战损伤、敌方冲撞先手、连续航程与弱补给。使用有限的贪心策略和代表性牌组，不能把失败解释为必败，也不能据此判定各系最优强度。此结果用于接舷数值校准，不能代替 Unity 内实际体验测试或端到端航程难度评估。
